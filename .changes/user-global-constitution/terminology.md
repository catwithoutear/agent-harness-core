# Terminology

## Terms

| Term | Meaning | Scope |
|---|---|---|
| user-global constitution | A short set of durable behavioral rules intended for a user's global agent instruction layer. | This change. |
| user-facing Chinese | Chinese output for plans, explanations, review reports, answers, and other material primarily read by the user. | Language boundary. |
| long-lived English assets | English content for repository README material, rules, skills, agent prompts, configuration, code, templates, and other machine-loaded or reusable assets. | Language boundary. |
| README_CN.md | Full Chinese translation of the core `README.md`, linked from the English README and kept in sync when README content changes. | Language boundary. |
| semantic README content | README meaning that affects sections, commands, install guidance, warnings, behavior claims, or user-facing instructions. | README sync rule. |
| semantic map | The pre-edit understanding of a file's ownership, dependencies, invariants, protected behavior, and smallest correct edit point. | Constitution rule. |
| bounded autonomy | Agent initiative that allows proportional adjacent fixes while requiring confirmation for high-impact direction changes. | Constitution rule. |
| agreed direction | A contract, plan, design, boundary, workflow, or acceptance criterion explicitly settled with the user. | Constitution rule. |
| verification | The smallest credible check that proves the requested outcome in the current context. | Constitution rule. |
| traceability | Evidence links for important conclusions, design choices, reviews, and handoffs. | Constitution rule. |
