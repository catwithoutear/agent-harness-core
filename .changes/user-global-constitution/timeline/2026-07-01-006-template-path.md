# Template Path

## Event

During `grill-with-docs`, the user accepted changing the constitution template path from `templates/agents/user-global-agent-constitution.md` to `templates/user-global/AGENTS.md`.

## Decision

Store the documentation-only user-global constitution template at `templates/user-global/AGENTS.md`.

## Evidence

- Coordinator recommendation: "模板路径改为 `templates/user-global/AGENTS.md`"
- User answer: "认同"

## Residual Risk

The path contains a file named `AGENTS.md`, which can be confused with the core repository's root `AGENTS.md`. References must use the full path when ambiguity is possible.
